Итоговое задание по дисциплине «Разработка на Python и инженерия данных»
Тема: Разработка информационной системы с REST API на Python и FastAPI в выбранной предметной области

## Решения, которые агент принял сам

- **Датасет:** Cardiovascular Disease dataset (Kaggle, 70 000 пациентов, таргет `cardio`).
- **Feature engineering:** возраст в годах, ИМТ и пульсовое давление.
- **Обработка выбросов:** при обучении удаляются строки с физиологически невозможными значениями,
  на инференсе такие значения прижимаются к границам.
- **Возраст в API** передаётся в днях, как в датасете, а интерфейс переводит годы в дни.
- **Frontend:**
  - HTML/JS без фреймворков, раздаётся тем же FastAPI;
  - форма с данными пациента, вердикт и вероятность, оговорка «не медицинский диагноз»;
  - загрузка CSV с превью и скачиванием результата;
  - загрузка модели и график ROC-AUC моделей;
  - чистые функции вынесены в `format.js` и покрыты тестами `node --test`;
  - линтинг — ESLint + Prettier.
- **Итоговый проект:** кардиологическая клиника. Шесть таблиц, пять бизнес-правил, ETL из `cardio_train.csv`,
  четыре аналитических эндпоинта, ML-оценка риска при сохранении медосмотра.
- **Часы работы клиники** заданы в часовом поясе клиники (`CLINIC_TIMEZONE`), а время в БД и API хранится в UTC.
- **Тесты на SQLite, боевая БД PostgreSQL:** в среде разработки PostgreSQL и Docker не было, поэтому работу
  с PostgreSQL проверяет только CI (задание `migrations`).
